# CmdTab 1.0.2

Packaging update; no runtime behavior changes.

- Keep the app bundle named `CmdTab.app`, independent of the internal version number.
- Include the Finder app icon directly in the project and in every release bundle.
- Continue to ship a universal build for Apple silicon and Intel Macs, requiring macOS 13 or later.

The app is ad-hoc signed and is not notarized. macOS may show a security warning the first time it is opened. Control-click the app and choose **Open** to approve it.
