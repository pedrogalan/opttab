# CmdTab 1.0.0

First public release of CmdTab, a per-app window switcher for macOS.

- Hold **Option** and press **Tab** to cycle through windows of the frontmost app; release Option to switch.
- View window thumbnails, including windows on other Spaces when enabled.
- Configure startup, menu bar visibility, thumbnail size, and required macOS permissions in Settings.
- Universal app for Apple silicon and Intel Macs, requiring macOS 13 or later.

The app is ad-hoc signed and is not notarized. macOS may show a security warning the first time it is opened. Control-click the app and choose **Open** to approve it.
