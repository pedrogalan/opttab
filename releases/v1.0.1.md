# CmdTab 1.0.1

Improved switching for apps that have windows on more than one Space.

- The switcher now lays out every window of the frontmost app — including windows on other Desktops — before the overlay appears. Cards no longer pop in while the switcher is open.
- Off-Desktop window discovery is much faster: the Accessibility scan stops once it has passed the app's window elements instead of running for a fixed 250 ms.
- The window list is pre-scanned in the background when an app becomes frontmost, so opening the switcher usually needs no scan at all.
- Minimized windows are now listed and can be restored from the switcher.

The app is ad-hoc signed and is not notarized. macOS may show a security warning the first time it is opened. Control-click the app and choose **Open** to approve it.
