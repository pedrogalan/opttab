# OptTab 2.0.0

CmdTab is now OptTab. This major release updates the app’s name and internal identity while keeping the GitHub repository and release history in place.

- The app, executable, settings, and app bundle are now named OptTab.
- OptTab migrates the previous CmdTab settings and Run at startup preference on first launch, then asks the old app to quit.
- macOS treats OptTab as a new app identity. Grant Accessibility and Input Monitoring again, and Screen Recording if you use thumbnails.
- Universal build for Apple silicon and Intel Macs; requires macOS 13 or later.

The app remains ad-hoc signed and is not notarized. macOS may show a security warning the first time it is opened. Control-click the app and choose **Open** to approve it.
